# 배포·인용 가이드

## 프로젝트 식별자

- 프로젝트/저장소: `lh2dt_models`
- Python 배포 이름: `lh2dt_models`
- Python 구현 import: `lh2dt`
- 현재 버전: `0.1.0`

## 로컬 배포 검증

```powershell
python -m pip install -e ".[dev]"
pytest -q
python -m build
python -m twine check dist/*
```

## GitHub

저장소를 `lyullee/lh2dt_models`로 만들고 `main` 브랜치를 push한다. 현장 원계측,
사진·영상, P&ID, 센터 태그와 비공개 구성파일은 저장소에 넣지 않는다.

## DOI

Zenodo 계정에서 GitHub를 연결한 뒤 `lyullee/lh2dt_models` 저장소를 Enable한다.
GitHub release `v0.1.0`을 만들면 Zenodo가 release를 보관하고 DOI를 발급한다.
`CITATION.cff`와 `.zenodo.json`은 release의 제목·버전·라이선스·설명을 자동으로
채우기 위한 메타데이터다. DOI가 발급되면 다음 버전에 DOI를 관련 식별자로
추가한다.

## PyPI

PyPI에서 프로젝트 이름이 사용 가능한지 확인한 뒤 API token 또는 Trusted
Publisher를 설정한다.

```powershell
python -m twine upload dist/*
```

API token은 저장소나 대화에 기록하지 않는다. GitHub Actions Trusted Publisher를
사용하면 release 시 `.github/workflows/publish-pypi.yml`이 OIDC로 PyPI에
업로드할 수 있다.
