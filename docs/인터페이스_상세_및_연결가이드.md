## 2. 상태·유량·결과 계약

모든 장치 결과는 가능한 경우 다음 정보를 함께 반환한다.

- 출구 `ThermoState`
- 부호가 있는 질량유량
- 엔탈피 유량 또는 열량
- 압력강하·운동량 잔차
- 누적 질량·에너지 장부
- 장치 내부 질량·에너지 잔차

```python
from lh2dt import HydrogenProperties, MassEnergyFlow

props = HydrogenProperties()
state = props.from_pT(130_000.0, 22.0)
flow = MassEnergyFlow(
    mass_flow_kg_s=0.01,
    specific_enthalpy_J_kg=state.specific_enthalpy_J_kg,
    source="inlet",
)
```

## 3. 저장탱크 연결

### 균질 탱크

```python
from lh2dt import HomogeneousTank, TankGeometry

tank = HomogeneousTank(
    TankGeometry(
        volume_m3=10.0,
        wall_heat_capacity_J_K=2.0e6,
        ambient_UA_W_K=8.0,
        fluid_wall_UA_W_K=15.0,
    ),
    props,
)
state0 = tank.initialize_saturated(
    pressure_Pa=130_000.0,
    liquid_volume_fraction=0.70,
)
```

### 층상 탱크

`LayeredTank`는 형상과 `LayeredTankParameters`를 직접 생성한다. 액체·기상·
벽체 셀 수와 열경계를 파라미터로 명시한다.

```python
from lh2dt import LayeredTank, LayeredTankParameters

parameters = LayeredTankParameters(
    liquid_cell_count=3,
    vapor_cell_count=3,
    wall_node_count=12,
    wall_heat_capacity_J_K=2.0e6,
    ambient_UA_W_K=8.0,
    # 나머지 계면·벽체·압력 범위 파라미터를 명시
)
tank = LayeredTank(shape, parameters, props)
state0 = tank.initialize_saturated(
    pressure_Pa=130_000.0,
    liquid_volume_fraction=0.70,
)
```

탱크를 계산할 때 첫 유효 PT는 초기 절대압력, DPT는 별도 액위 환산표를 거쳐
초기 재고량으로 사용한다. 이후 관측열은 callback으로 모델에 되먹임하지 않고
모델 출력과 비교한다.

## 4. 밸브·배관 포트 연결

```python
from lh2dt import Valve

valve = Valve(
    full_open_area_m2=1.0e-4,
    discharge_coefficient=0.70,
    properties=props,
)
result = valve.evaluate(upstream, downstream, opening=0.5)
print(result.mass_flow_kg_s, result.outlet)
```

배관은 같은 `ThermoState` 포트 계약을 사용한다. 장치를 연결할 때 유량의
부호를 바꾸지 않고, 각 장치가 반환한 출구 상태와 유량을 다음 장치의 입력으로
전달한다.

## 5. 네트워크 연결

정상 네트워크는 `JunctionNode`와 `NetworkLink`로 구성한다.

```python
from lh2dt import JunctionNode, NetworkLink, SteadyNetwork

network = SteadyNetwork(nodes, links, properties=props)
solution = network.solve()
for link_id, link_solution in solution.links.items():
    print(link_id, link_solution.mass_flow_kg_s)
```

시간변화가 있는 탱크·배관·기화기·재액화기는 `DynamicNetworkSimulator`에
동적 노드 어댑터로 등록한다. 어댑터는 매 시간단계에 다음을 제공해야 한다.

1. 현재 상태의 `ThermoState` 및 장치 결과
2. 외부 경계 질량·에너지 유량
3. 다음 상태와 질량·에너지 잔차

## 6. 계측 어댑터

```python
from lh2dt import (
    FirstOrderTransmitter, PMD75BHartObservation,
    TransmitterParameters,
)

transmitter = FirstOrderTransmitter(TransmitterParameters(
    lower_range=0.0,
    upper_range=2.0e6,
    time_constant_s=2.0,
    resolution=10.0,
    accuracy_fraction_of_span=0.001,
))
hart = PMD75BHartObservation(transmitter)
state = hart.initialize(position_adjusted_pressure=130_000.0)
state, variables = hart.advance(
    state,
    raw_sensor_pressure=129_900.0,
    position_adjusted_pressure=130_000.0,
    sensor_temperature=295.0,
    electronics_temperature=300.0,
    time_step_s=1.0,
)
print(variables.as_dict())
```

계측기 범위·시정수·교정값이 확인되지 않은 상태에서 임의의 HART 주소나
정확도를 추정하지 않는다. 해당 값이 없으면 관측 구조만 생성하고 실제 표시값
변환은 보류한다.

## 7. 데이터 연결 규칙

입력 데이터에는 최소한 다음 필드가 있어야 한다.

- `timestamp`
- 압력·온도·유량·밸브 명령의 채널명
- 각 채널의 단위
- 압력의 절대압/게이지압 기준
- 시간대와 샘플링 간격
- 결측·보간·품질 플래그

권장 실행 순서는 다음과 같다.

1. timestamp 정렬과 중복 제거
2. 단위와 압력 기준 검증
3. 첫 유효 행으로 초기조건 설정
4. 운전 경계만 모델 입력으로 연결
5. 모델 전방계산 수행
6. 이후 관측열을 모델 출력과 정렬해 비교
7. 질량·에너지·운동량 잔차 확인

센서의 매 시점 값을 모델 상태에 넣으면 검증이 아니라 관측 궤적 재현이 되므로,
독립 검증에서는 관측값 되먹임을 사용하지 않는다.

## 8. 출력 시계열 표준

외부 시스템으로 내보낼 때는 다음 표준 열을 권장한다.

| 열 | 단위 | 의미 |
|---|---:|---|
| `timestamp` | ISO 8601 | 결과 시각 |
| `pressure_Pa_abs` | Pa | 모델 절대압력 |
| `temperature_K` | K | 대표 또는 셀 온도 |
| `liquid_mass_kg` | kg | 액체 질량 |
| `vapor_mass_kg` | kg | 기상 질량 |
| `liquid_level_m` | m | 액면 높이 |
| `evaporation_rate_kg_s` | kg/s | 증발률 |
| `heat_leak_W` | W | 외기 유입열 |
| `mass_residual_kg` | kg | 질량 보존 잔차 |
| `energy_residual_J` | J | 에너지 보존 잔차 |

계측 표시값은 별도 접미사를 사용한다. 예를 들어 `PT1105A_pv`,
`DPT1101_qv`, `TT1116_sv`처럼 물리모델 출력과 구분한다.

## 9. 생산 모델과 피팅 모델의 분리

생산용 모델은 형상, 물성, 공개 상관식, 제작사 정격, 명시된 경계조건만
사용한다. 특정 시험일에 맞춘 UA·열용량·유량계수는 별도 분석 스크립트에서만
추정하며, 기본 모델의 파라미터를 자동 변경하지 않는다.

## 10. 모델 선택

같은 실제 장비에 여러 모델을 동시에 넣는 것이 아니다.

- 빠른 평균 거동: `HomogeneousTank`
- 상부·하부 벽체 차이: `StratifiedTank`
- 액체·기상·벽체 셀 동특성: `LayeredTank`
- 반경·축방향 국부 열장: `RadialAxialTank`

실제 탱크가 네 대라면 선택한 모델 클래스를 네 번 생성하고, 각 탱크의 상태와
경계를 분리한다. P&ID상 연결이 있을 때만 네트워크 포트로 연결한다.
