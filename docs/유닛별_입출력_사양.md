# 유닛별 입력·출력 사양

이 문서는 코드에서 모델을 연결할 때 필요한 **구성 입력**, **운전 입력**,
**출력**을 한눈에 정리한 것이다. 정확한 Python 생성자와 결과 dataclass의
전체 필드는 `src/lh2dt`의 해당 모듈에서 확인할 수 있다.

## 공통 계약

| 객체 | 주요 입력 | 주요 출력 |
|---|---|---|
| `ThermoState` | `pressure_Pa`, `temperature_K` 또는 물성 변환용 상태쌍 | 압력·온도·밀도·비엔탈피·내부에너지·엔트로피·품질·상 |
| `MassEnergyFlow` | `mass_flow_kg_s`, `specific_enthalpy_J_kg`, `source` | `enthalpy_flow_W = mass_flow × enthalpy` |
| `EnergyTransfer` | `heat_W`, `shaft_work_into_fluid_W` | 유체로 들어간 총 에너지율 |
| `HydrogenProperties` | 유체명(기본 `ParaHydrogen`) | `from_pT`, `from_ph`, `from_rho_u`, 포화액/포화증기 상태 |

모든 압력은 **Pa 절대압**, 온도는 **K**, 질량유량은 **kg/s**, 비엔탈피는
**J/kg**, 열량·축동력은 **W**, 체적은 **m³**이다. 유량은 수신 제어체적으로
들어오면 양수, 나가면 음수이다.

## 저장탱크 유닛

| 클래스 | 구성 입력 | 운전 입력 | 출력 |
|---|---|---|---|
| `HomogeneousTank` | `TankGeometry(volume_m3, wall_heat_capacity_J_K, ambient_UA_W_K, fluid_wall_UA_W_K)` | 초기 `pressure_Pa`, `liquid_volume_fraction`, 벽 온도; 시간·외기온도·`MassEnergyFlow` callback | `TankStepResult`: `state`, `thermo`, 누적 경계 질량/에너지, `total_energy_residual_J` |
| `StratifiedTank` | `HorizontalVesselGeometry`; `StratifiedTankParameters`의 하부/상부 벽 열용량·UA, 액/기 벽전달, 계면 UA, 축방향 UA, 압력 범위 | 초기 압력·액체 체적분율·하/상부 벽 온도; 액상·기상 유량 callback | `StratifiedTankStepResult`: 액/기 상태, 하·상부 벽 상태, 질량·에너지 잔차 |
| `LayeredTank` | 형상; `LayeredTankParameters`의 액체/기체/벽 셀 수, 벽 열용량·UA, 축방향 전도, 연결 기상 데드볼륨·노즐 벽 열용량, 계면/Schrage/분산비등/벽 순환 모델, 압력 범위 | 초기 압력·액체 체적분율 또는 액체/기체/벽 온도 프로파일; 셀별 유량·직접 열원·외기온도; `time_step_s` | 셀별 `LayeredTankState`, 계면 온도·압력·증발률, 누적 증발/잠열/분산비등, 질량·에너지 잔차 |
| `RadialAxialTank` | 전체 체적, 액/기 레벨 수, 코어·벽 체적분율, 경계 형상, 방사·축방향 전도도, 벽 열용량·UA, 계면 UA/면적, 분산비등 및 압력 범위 | 초기 압력·액체 체적분율·벽 온도; 셀별 유량과 직접 열원 | 반경·축 셀별 상태, `RadialAxialTankDerivative`, 질량·에너지 잔차 |

탱크 모델에서 관측 PT/DPT/TT는 기본적으로 **비교 출력**이다. 입력으로
넣는 것은 초기 상태와 실제 운전을 결정하는 유량·밸브 상태·외기/진공 경계이며,
관측 압력을 매 시점에 되먹임하지 않는다.

## 열경계·단열 유닛

| 클래스 | 구성/운전 입력 | 출력 |
|---|---|---|
| `VacuumInsulation` | `area_m2`, 유효 방사율, MLI/고체 전도, 지지대 전도, 잔류가스 계수, 진공압력 허용범위, 국부 열경로 | 복사·MLI·지지대·잔류가스·국부 열량, 총 냉측 유입열, 등가 UA |

| `NaturalConvection`/`NaturalCirculationLoop` | 유체 상태, 특성 길이·면적, 중력, 경계 온도, 재질/점도 상관식 | 대류 열전달계수, 열량, 순환 유량·잔차 |

## 범용 조립

`component_factory.build_asset_model(asset, properties=None, model_override=None)`에
`asset_id`, `component_model`, `model_parameters`, `source`를 넣으면 완전한
파라미터일 때만 해당 유닛을 생성한다. 누락 파라미터는 `AssetModelBuild`의
`missing_parameters`와 `issues`로 반환되며 임의 기본값으로 채우지 않는다.
