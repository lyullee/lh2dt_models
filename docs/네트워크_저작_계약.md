# 네트워크 저작 계약

`NetworkDraft`는 아이콘 기반 공정 편집기와 수치해석기를 분리하는 JSON 계약이다.
노드는 탱크·밸브·배관 같은 모델 종류와 화면상의 위치를 갖고, 포트는 액체·기상·
열·신호 역할과 방향을 갖는다. 링크는 출발 노드/포트, 도착 노드/포트, 링크 모델과
그 파라미터를 보존한다.

```python
from lh2dt import NetworkDraft, load_network_draft, save_network_draft

draft = load_network_draft("network.json")
issues = draft.validate()
if not draft.ready:
    raise ValueError(issues)
```

이 계약은 다음을 보장한다.

- 노드 ID와 포트 ID가 중복되지 않는다.
- 연결선이 존재하지 않는 노드나 포트를 참조하지 않는다.
- 편집기의 위치·레이블·메타데이터가 물리 파라미터와 함께 재현된다.
- 화면에서 장치를 이동·복제·교체해도 모델 방정식은 변경되지 않는다.

현재 계약은 GUI를 포함하지 않으며, 실제 solver `SteadyNetwork` 또는
`DynamicNetworkSimulator`를 생성하는 응용 프로그램이 `NetworkDraft`를 해석한다.
따라서 센터별 태그와 운전자료는 별도 비공개 어댑터로 남고, 공개 패키지는 편집기와
수치모델 사이의 안정된 연결 포맷만 제공한다.
