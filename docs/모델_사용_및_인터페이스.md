# 모델 사용 및 인터페이스

## 상태와 단위

모델 내부의 단위 계약은 다음과 같다.

| 값 | 단위 | 방향/기준 |
|---|---:|---|
| 압력 | Pa | 절대압. 게이지압은 경계에서 변환 |
| 온도 | K | 절대온도 |
| 질량 | kg | 저장요소의 총량 또는 셀별 양 |
| 질량유량 | kg/s | 수신 제어체적으로 들어오면 양수 |
| 비엔탈피 | J/kg | 유체가 경계를 통과할 때의 운반 에너지 |
| 열량/동력 | W | 제어체적으로 들어오면 양수 |
| 체적 | m³ | 형상과 데드볼륨을 분리해 입력 |

`ThermoState`는 압력·온도·밀도·비엔탈피·내부에너지·품질을 한 묶음으로
전달한다. 하나의 부품에서 계산한 상태를 다음 부품에 그대로 넘기며, 숫자만
넘기는 경우에는 반드시 `ThermoState` 생성자를 거쳐 유효성 검사를 통과시킨다.

## 부품 연결 계약

### 저장요소

`HomogeneousTank`, `StratifiedTank`, `LayeredTank`, `RadialAxialTank`는 공통으로
다음 역할을 갖는다.

- `initialize_*`: 압력·액체 체적분율·열상태로 질량과 에너지를 초기화한다.
- `thermo(state)`: 현재 상태에서 물성 상태를 계산한다.
- `simulate(...)`: 일정한 시간간격의 RK4 적분을 실행한다.
- 결과의 누적 경계 질량/에너지와 에너지 잔차로 폐합을 확인한다.

`LayeredTank`와 `RadialAxialTank`는 액체·기체·벽체 온도를 셀별로 유지하므로
초기 상·하부 온도차와 벽체 축방향 전도를 모델에 직접 넣을 수 있다.

### 유량과 장치

```python
MassEnergyFlow(
    mass_flow_kg_s=0.01,             # 수신 체적으로 유입
    specific_enthalpy_J_kg=1.2e5,
    source="upstream-valve",
)
```

`Valve`, `HEMPipe`, `Vaporizer`, `Reliquefier`, `Pump`, `Compressor`는 입구
`ThermoState`와 장치 파라미터를 받아 `*Result`를 반환한다. 결과에는 질량유량,
출구 상태, 압력강하, 열량과 필요한 경우 운동량 잔차가 들어 있다. 닫힌 밸브도
seat leakage를 명시한 경우에만 누설을 만든다.

### 정상·동적 네트워크

정상망은 `JunctionNode`와 `NetworkLink`를 `SteadyNetwork`에 등록하고 압력망을
풀이한다. 시간변화가 필요한 경우 `DynamicNetworkSimulator`에 저장요소 노드,
동적 배관/기화기/재액화기 노드와 외부 경계 노드를 등록한다. 노드 adapter는
각 단계에서 다음 세 값을 반환한다.

1. 다음 상태 또는 장치 결과
2. 외부 경계로 드나든 질량·에너지 유량
3. 노드 내부 보존식 잔차

여러 탱크를 연결할 때 내부 이송은 총괄 장부에서 상쇄되어 외부 경계와
구분된다. `NetworkSolution`의 링크별 잔차와 최대 운동량 잔차를 기록하면
연결 순서가 바뀌어도 폐합을 재현할 수 있다.

## 시험 데이터 연결

시험 데이터의 최소 공통 키는 `timestamp`이다. 관측 압력·온도는 다음 두
단계로 사용한다.

1. 첫 유효 행으로 초기 압력/열상태를 정한다.
2. 이후 관측 행은 경계조건으로 주입하지 않고 모델 출력과 비교한다.

밸브 개도, 질량유량, 외기온도, 진공압력처럼 실제 운전을 결정하는 값은
별도의 경계 채널로 명시한다. 채널 단위와 압력 기준이 확정되지 않은 경우
자동 추정을 금지하고 입력 검증에서 중단한다.

## 계측 어댑터

`FirstOrderTransmitter`는 센서 지연을 1차 동특성으로 표현하고,
`PMD75BHartObservation`은 DPT의 PV/SV/TV/QV를 관측 메타데이터로 보존한다.
계측기 출력은 모델 상태를 바꾸지 않으며, 모델 상태에서 센서 표시값을
생성하는 후단 어댑터로 사용한다. 따라서 HART 보조변수를 물리 입력으로
중복 주입하지 않는다.

## 모델 교체와 확장

새 장치는 다음 구조를 따르면 기존 네트워크에 연결할 수 있다.

1. 입력 파라미터를 불변 `dataclass`로 정의한다.
2. `evaluate`/`step`에서 유한성·단위·방향을 검사한다.
3. 출력에 출구 상태와 보존식 잔차를 포함한다.
4. `contracts.py`의 2-port 검증기를 호출한다.
5. 질량·에너지 폐합과 시간간격 수렴 테스트를 추가한다.

피팅 계수는 기본 파라미터에 숨기지 않는다. 공개 상관식 또는 제작사 정격을
명시적으로 입력하고, 특정 시험 데이터로 추정한 값은 별도 실험 스크립트에서만
관리한다.
