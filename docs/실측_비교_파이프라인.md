# 실측 비교 파이프라인

`lh2dt.data_pipeline`은 현장 CSV 또는 historian export를 물리모델과 비교하기
위한 경계 계층이다. 센서값은 모델 상태에 되먹임하지 않고, 초기조건·경계조건과
분리된 관측열로 유지한다.

## 처리 순서

1. `ChannelSpec`으로 각 열의 의미, 단위, 압력 기준, 품질 열을 선언한다.
2. `load_observation_csv`로 timestamp를 읽고 초 단위 상대시간으로 변환한다.
3. 게이지압은 `pressure_basis="gauge"`로 명시해 절대 Pa로 변환한다.
4. 결측값과 품질 불량값은 `valid_masks`에서 제외하며 보간하지 않는다.
5. 정렬 또는 중복 제거가 필요하면 함수 호출에서 명시하고 `repairs`에 기록한다.
6. `select_quiet_windows`로 6–12시간 정숙 후보를 찾는다. 압력 span이 10 kPa
   이상이고 이벤트 열이 바뀌지 않은 구간만 후보가 된다.
7. `split_validation_window`에서 첫 30–60분을 초기화 구간으로 분리하고,
   이후 4–8시간을 blind 구간으로 고정한다.
8. 모델을 초기화 구간에서 한 번만 설정한 뒤 `compare_forward_window`로 blind
   구간의 nMAPE, RMSE, 불확도 내 비율을 계산한다.

한 파일에 여러 자산이 섞여 있으면 `row_filter`를 명시해 한 탱크의 행만 선택한다.
필터는 행을 자동으로 추정하지 않으므로 자산 열과 선택 규칙을 실행 기록에 남긴다.

## 예시

```python
from lh2dt import (
    ChannelSpec, load_observation_csv, select_quiet_windows,
    split_validation_window, compare_forward_window,
)

channels = [
    ChannelSpec("PT1105A", "tank_pressure", "pressure", "MPa", "gauge", "PT1105A_Q"),
    ChannelSpec("DPT1101", "tank_level_dpt", "differential_pressure", "mmH2O", "differential"),
    ChannelSpec("TT1111", "tank_temperature", "temperature", "degC"),
    ChannelSpec("VENT_CMD", "vent_command", "value", "", required=False),
]
table = load_observation_csv(
    "private/center_tank_export.csv", channels,
    timestamp_column="timestamp",
)
windows = select_quiet_windows(
    table, "tank_pressure", min_duration_s=6*3600,
    max_duration_s=12*3600, min_pressure_span_Pa=10_000,
    event_columns=("vent_command",),
)
split = split_validation_window(table, windows[0], initialization_s=3600,
                                blind_duration_s=4*3600)

# model_time_s/model_pressure_Pa are generated by the fixed-parameter model.
metrics = compare_forward_window(
    model_time_s, model_pressure_Pa, table, split, "tank_pressure",
    capacity_reference=1_000_000.0,
)
print(metrics)
```

`capacity_reference`는 설비 정격 또는 시험 문서에서 명시한 비교 기준이어야
한다. 관측값의 평균·범위에서 자동으로 만들면 nMAPE가 아니므로 함수가 대신
추정하지 않는다.

## 데이터 계약

| 항목 | 규칙 |
|---|---|
| timestamp | ISO-8601, 단조 증가. 정렬·중복 처리는 호출자가 명시 |
| 압력 | `absolute` 또는 `gauge`를 반드시 선언. 내부는 Pa(abs) |
| DPT | 물리 압력과 액위 환산을 분리. HART 범위는 설정 어댑터에서 제공 |
| 온도 | K 또는 degC를 선언. 내부는 K |
| quality | 품질 열이 있으면 유효 마스크에 반영. 불량값 보간 금지 |
| 이벤트 | 밸브/명령 열은 정숙 구간 분할에만 사용하고 모델 경계로 별도 연결 |

## 비공개 설비 설정

설비 형상·단열·데드볼륨·센서 매핑은 공개 저장소 밖의 `private` JSON/YAML로
관리한다. `asset_inputs`의 `load_evidenced_asset_catalog`와
`audit_evidenced_asset_catalog`는 각 파라미터에 단위, 출처, 불확도, 적용 대상을
요구한다. `parameter_policy.plant_data_optimization`은 반드시 `false`여야 하며,
관측 시계열로 파라미터를 자동 보정하지 않는다.
