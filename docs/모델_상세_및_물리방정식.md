# LH2DT 모델 상세 설명서

이 문서는 `lh2dt_models`가 제공하는 액화수소 설비 모델의 상태변수, 보존식,
열전달, 상변화, 유동, 계측 계층을 설명한다. 모델은 특정 센터의 태그나
시계열을 기본값으로 포함하지 않으며, 형상·물성·장치 정격·경계조건을 명시해
생성하는 것을 원칙으로 한다.

## 1. 전체 구조

모델은 네 계층으로 나뉜다.

1. **물성 계층**: Para-Hydrogen의 압력·온도·밀도·엔탈피·내부에너지·품질을
   일관된 `ThermoState`로 변환한다.
2. **장치 계층**: 탱크, 밸브, 배관, 기화기, 재액화기, 펌프, 압축기와 열경계를
   각각 계산한다.
3. **네트워크 계층**: 장치의 포트를 `JunctionNode`와 `NetworkLink`로 연결해
   질량·에너지·운동량 폐합을 확인한다.
4. **계측·제어 계층**: 물리 상태를 전송기 표시값과 HART PV/SV/TV/QV로
   변환하고, PID 출력으로 장치 개도를 명령한다.

모델 내부 압력은 Pa 절대압, 온도는 K, 질량유량은 kg/s, 비엔탈피는 J/kg,
열량과 동력은 W, 체적은 m³이다. 게이지압은 경계에서 절대압으로 변환한 뒤
모델에 전달한다.

## 2. 공통 열역학 계약

### `ThermoState`

`ThermoState`는 다음 값을 함께 보존한다.

- `pressure_Pa`
- `temperature_K`
- `density_kg_m3`
- `specific_enthalpy_J_kg`
- `specific_internal_energy_J_kg`
- `specific_entropy_J_kgK`
- `quality` 및 상 정보

상태 변환은 `HydrogenProperties.from_pT`, `from_ph`, `from_rho_u`,
`saturated_liquid`, `saturated_vapor`를 사용한다. 장치 사이에 압력·온도만
개별 숫자로 전달하기보다 `ThermoState`를 전달해 단위와 유효성을 함께 검사한다.

### `MassEnergyFlow`

경계를 통과하는 유체는 질량유량과 비엔탈피로 표현한다.

```python
MassEnergyFlow(
    mass_flow_kg_s=0.01,              # 제어체적으로 유입
    specific_enthalpy_J_kg=1.2e5,
    source="upstream-valve",
)
```

엔탈피 유량은 다음과 같다.

\[
\dot H = \dot m h
\]

유입은 양수, 유출은 음수로 기록한다. 각 장치는 외부 경계 질량·에너지와
내부 수송을 별도 장부로 반환한다.

## 3. 저장탱크 물리모델

### 3.1 균질 평형 탱크: `HomogeneousTank`

탱크 전체를 하나의 평균 유체 제어체적으로 표현한다. 액체와 기상은 평형
품질로 분해하며, 벽체는 하나의 열용량으로 표현한다.

구성 입력은 탱크 체적, 벽체 열용량, 외기-벽체 `UA`, 유체-벽체 `UA`이다.
운전 입력은 초기 압력, 액체 체적분율, 벽체 온도, 외기온도, 유입·유출
`MassEnergyFlow`, 직접 열원이다.

상태는 수소 총질량 \(m\), 수소 총 내부에너지 \(U\), 벽체 온도 \(T_w\)로
구성한다.

\[
\frac{dm}{dt}=\sum_i \dot m_i
\]

\[
\frac{dU}{dt}=\sum_i \dot H_i + Q_{amb\rightarrow wall}
                 + Q_{wall\rightarrow fluid}+Q_{direct}
\]

\[
C_w\frac{dT_w}{dt}=Q_{amb\rightarrow wall}-Q_{wall\rightarrow fluid}
\]

출력은 탱크 압력, 온도, 액체·기상 질량·체적, 품질, 누적 경계 장부와
에너지 잔차다.

### 3.2 2영역 층상 탱크: `StratifiedTank`

액체와 기상을 별도의 제어체적으로 유지한다. 하부 벽체와 상부 벽체를
분리해 액체 젖음부와 기상 접촉부의 열경계를 다르게 줄 수 있다.

액체·기상 질량 및 내부에너지, 하부·상부 벽체 온도를 상태로 둔다. 액체와
기상 사이의 상변화는 계면 열수지에 의해 결정되며, 액체·기상 유량과 계면
열전달량을 각각 기록한다.

### 3.3 다중 셀 층상 탱크: `LayeredTank`

현재 저장탱크 전방 오차시험의 기준 모델이다. 액체 셀, 기상 셀, 벽체 절점을
각각 배열로 유지한다. 모든 셀은 강체 탱크의 공통 압력 제약을 공유한다.

상태 배열은 다음과 같다.

- 액체 셀 질량 및 비엔탈피
- 기상 셀 질량 및 비엔탈피
- 벽체 절점 온도
- 공통 압력

모델은 다음 효과를 선택 가능한 물리 경계로 제공한다.

- 액체·기상 셀 간 물질·에너지 수송
- 액체-기상 계면 전도 열전달
- 평형 에너지 점프 상변화
- Schrage 계면 질량플럭스
- 포화 액체 분산 비등
- 벽체 축방향 전도
- 벽체 자연순환
- 외기 및 진공단열 열경계
- 연결 배관·노즐 기상 데드볼륨
- 연결부 벽체 열용량
- 선택적 폐쇄 누설·릴리프 경계

각 시간단계 결과에는 계면 온도·압력, 증발률, 분산 비등률, 잠열, 셀별
열전달량, 누적 증발량, 질량·에너지 잔차가 포함된다.

### 3.4 반경-축 탱크: `RadialAxialTank`

액체와 기상을 축방향 레벨과 반경방향 코어·벽체로 분해한다. 벽체와 유체의
방사방향 및 축방향 전도를 명시적으로 계산하므로 국부 열경계나 상·하부
비대칭 온도장을 표현할 때 사용한다.

## 4. 열경계와 단열

`VacuumInsulation`은 복사, MLI, 지지대 전도, 잔류가스 전도, 국부 열경로를
분리 계산한다.

총 유입열은 다음처럼 합산한다.

\[
Q_{in}=Q_{rad}+Q_{MLI}+Q_{support}+Q_{gas}+Q_{local}
\]

`NaturalConvection`과 `NaturalCirculationLoop`은 벽체-유체 대류와 셀 간
자연순환 열량을 계산한다. 이 결과는 탱크 방정식에 직접 열원으로 더해지며,
임의의 경험 피팅계수로 대체하지 않는다.

## 5. 배관·밸브·벤트

### 밸브

`Valve`는 유효 개구면적, 방출계수, 개도율, 상·하류 상태로 질량유량을
계산한다. 압력비가 임계조건을 넘으면 초크 유동을 처리하고, 닫힘 누설은
`closed_leakage_CdA_m2`를 명시한 경우에만 활성화한다.

`CheckValve`, `PressureReliefValve`, `TemperatureProtectionValve`는 각각
역류 방지, 설정압력 히스테리시스, 온도 트립 경계를 추가한다.

### 배관

`Pipe`는 Darcy–Weisbach 마찰과 국부손실을 사용한다.

\[
\Delta p=f\frac{L}{D}\frac{\rho v^2}{2}
            +K\frac{\rho v^2}{2}+\rho g\Delta z
\]

`HEMPipe`는 2상 HEM 팽창을 사용하고, `DynamicHEMPipe`는 배관 유체와 벽체
온도를 시간 적분한다. `VentStack`은 벤트 배관의 유량·압력강하·외기 열유입을
계산한다.

## 6. 기화기와 재액화기

`Vaporizer`는 입구 상태, 출구 압력, 유량, 열원 온도, `UA`, 최대 열량으로
출구 상태와 기화 완료 여부를 계산한다. `AmbientAirVaporizer`는 외부 자연대류,
복사, 서리 생성·융해를 추가한다.

`DynamicVaporizer`는 유체 체적과 벽체 열용량을 상태로 적분한다. 병렬 설비는
`ParallelDynamicVaporizer`로 유닛별 상태와 집계 열량을 동시에 반환한다.

`Reliquefier`는 냉각능력과 목표 품질을 사용해 제거열량과 액화 질량분율을
계산한다. `DynamicReliquefier`는 냉측 온도·`UA`, 유체·벽체 열용량을 포함하며,
`ParallelDynamicReliquefier`는 여러 냉각 유닛의 상태를 집계한다.

## 7. 펌프와 압축기

`Pump`는 지정 압력상승과 효율을 사용한다. `VirtualPump`는 shutoff 압력상승과
runout 유량 사이의 H-Q 관계를 선형화한다. `MappedPump`는 실제 H-Q·효율·NPSH
곡선을 사용해 운전점을 계산한다.

`Compressor`는 압력비와 등엔트로피 효율로 출구 상태와 축동력을 계산한다.

## 8. 네트워크와 보존식

`SteadyNetwork`는 접점 압력·엔탈피를 풀고, `DynamicNetworkSimulator`는 탱크,
동적 배관, 기화기, 재액화기를 시간 적분한다. 모든 링크에는 유량, 출구 상태,
압력강하 및 운동량 잔차가 기록된다.

내부 장치 사이에서 이동한 질량과 에너지는 총괄 장부에서 상쇄되고, 외부
경계만 시스템 순유입·순유출로 남는다. 따라서 연결 순서를 바꾸어도 질량·
에너지 폐합을 확인할 수 있다.

## 9. 계측과 제어

`FirstOrderTransmitter`는 시정수, 범위, scale/bias, 분해능, 포화를 계산한다.
`PMD75BHartObservation`은 DPT 관측을 다음 네 변수로 보존한다.

- PV: 감쇠·위치보정 후 압력
- SV: 센서 온도
- TV: 전자부 온도
- QV: 감쇠·위치보정 전 센서 압력

이 변수들은 계측 계층의 출력이며, 동일한 센서값을 물리 입력으로 중복 주입하지
않는다. `PIDController`는 setpoint와 측정값에서 P/I/D 항, 포화, 다음 제어상태를
반환한다.

## 10. 검증 원칙

검증은 다음 순서로 수행한다.

1. 물성 상태의 유효성 확인
2. 시간간격 수렴 확인
3. 질량·에너지·운동량 잔차 확인
4. 초기조건과 경계조건 고정
5. 계측값 되먹임 없이 전방 계산
6. 출력 시계열과 독립 비교

현장 시계열에 자동 피팅한 값은 생산 기본모델에 넣지 않는다. 피팅이 필요한
정량 보고서는 별도 실험으로 관리하며, 물리모델의 구성 입력과 구분한다.
