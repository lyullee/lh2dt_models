# 물리모델 구조와 방정식

## 물성

`HydrogenProperties`는 CoolProp의 Para-Hydrogen 상태방정식을 사용해
`(p,T)`, `(p,h)`, `(rho,u)` 상태를 서로 변환한다. 모든 제어체는 같은
엔탈피/내부에너지 기준을 사용하므로 장치 경계에서 에너지를 임의로 재설정하지
않는다. 포화액과 포화증기는 같은 압력에서 계산하여 2상 혼합의 품질과 잠열을
구성한다.

## 균질 탱크

강체 체적 `V`에서 총 질량과 내부에너지는 다음 보존식을 따른다.

```text
dM/dt = Σ m_dot
dU/dt = Σ(m_dot h)_in/out + Q_wall
```

유출 엔탈피는 탱크의 현재 상태에서 계산한다. 이 식과 EOS를 함께 풀어
압력·온도·품질을 얻는다. 벽체는 별도 열용량 `C_wall`을 가지며,

```text
C_wall dT_wall/dt = UA_ambient (T_ambient - T_wall)
                         - UA_fluid (T_wall - T_fluid)
                         + Q_direct
```

로 계산한다.

## 층상·다중셀 탱크

액체 `i`, 기체 `j`, 벽체 `k` 셀에 대해 질량·엔탈피 수지를 각각 적분한다.
셀 사이의 전도·자연대류·벽체 순환은 인접 셀의 열/질량 교환으로 표현한다.
강체 탱크와 연결 데드볼륨은 공통 압력 제약을 공유하며, 압력 투영 단계에서
전체 유체 내부에너지와 질량을 보존한다. 초기화 시 액체·기체·벽체의 온도
프로파일을 별도로 입력할 수 있다.

## 상변화

계면 열수지는 sensible heat와 잠열을 분리한다. 계면 질량플럭스는 Schrage
관계식과 기체막 열전달 선택식으로 계산하며, 액체·기체 라벨이 포화선을
넘지 않도록 상변화 보존형 투영을 적용한다. 분산 비등 모드는 셀별 과열도와
접액면적을 사용한다.

## 진공단열 및 벽 열경로

진공 재킷 열유입은 다음 항을 합산한다.

- 외면–내면 복사 교환
- MLI 또는 고체층의 유효 전도
- 지지대 열교
- 잔류가스 전도
- 국부 열경로와 연결 노즐/배관의 열용량

`VacuumInsulationParameters`가 각 항을 명시하므로 전체 UA 하나로 현장
압력곡선을 맞추지 않는다. 벽 노드는 상·하부 또는 축방향으로 분할할 수 있다.

## 유동과 장치

- 밸브와 HEM 배관은 압력차·총수두를 사용해 흐름 방향을 결정하고 등엔탈피
  팽창 또는 2상 질량플럭스를 계산한다.
- 동적 HEM 배관은 유체 질량·내부에너지와 금속 벽체 온도를 유한체적으로
  적분한다.
- 기화기는 유체측 엔탈피 증가, 열원측 열량, 압력강하를 동시에 계산한다.
- 재액화기는 냉열 입력과 응축 잠열을 에너지 수지로 연결한다.
- 펌프/압축기는 운전점·효율 또는 명시된 H-Q 곡선을 사용한다.
- 보호밸브·벤트 스택은 설정압력, 히스테리시스, 방출 경계를 분리해 표현한다.

## 수치 보존과 검증

각 동적 결과는 경계 누적 질량·에너지와 상태 장부를 반환한다. 다음 잔차를
확인한다.

```text
R_mass   = M_final - M_initial - ∫ m_dot_boundary dt
R_energy = E_final - E_initial - ∫ (m_dot h + Q_boundary) dt
```

정상 네트워크는 링크별 운동량 잔차와 최대 잔차를 반환한다. 시간간격을
절반으로 줄였을 때 관측량 변화가 줄어드는지 `compare_step_refinement`로
확인한다. NASA TN D-4171 표는 코드에 함께 제공되는 공개 기준 데이터이며,
실증 데이터 정확도와 혼동하지 않는다.

## 적용 한계

형상·배관 체적·밸브 계수·열경계가 확정되지 않은 설비에는 단일 결과를
자동으로 확정하지 않는다. 특히 2상 배관의 유동상태, 계측기 압력 기준,
기화기 외기 경계는 호출자가 명시해야 한다. 이러한 명시 경계가 없으면
모델은 오류를 내고 임의의 피팅값이나 조용한 외삽을 적용하지 않는다.
