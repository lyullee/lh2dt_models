# 검증과 재현성

## 로컬 테스트

```powershell
python -m pip install -e ".[dev]"
pytest -q
```

테스트는 물성 변환, 형상 적분, 밸브 방향성, 유량·에너지 보존, 탱크별
상변화, 동적 배관, 네트워크 연결, NASA 공개 기준을 확인한다. 현장 데이터나
센터 설정파일을 읽지 않으므로 다른 환경에서 동일한 코드를 실행할 수 있다.

## 공개 기준시험

`examples/run_nasa_d4171_benchmark.py`와 `lh2dt.benchmarks`는 NASA TN D-4171의
공개 표를 읽어 층상 열전달·자연순환·계면 상변화 모델을 비교한다. 이 시험은
상관식의 구조적 동작과 보존을 확인하는 기준선이며, 특정 탱크의 정확도 점수를
의미하지 않는다.

## 정량 비교 규칙

시계열 비교는 동일한 timestamp, 동일한 압력 기준, 동일한 경계조건을 사용한다.
기본 지표는 용량 정규화 nMAPE이며, 동적 압력변화가 작은 구간에서는 절대오차와
동적 excursion 지표를 함께 기록한다. 모델 출력에 관측값을 되먹임하거나,
비교 구간마다 열전달계수를 다시 맞추지 않는다.

## 재현 패킷 작성법

외부 시험기관에 모델을 넘길 때 다음 세 파일을 함께 보존한다.

1. 입력 JSON/CSV: 형상, 물성, 열경계, 초기상태, 경계 이벤트
2. 실행 스크립트: 패키지 버전과 시간간격을 고정한 호출 코드
3. 결과 CSV: timestamp, 예측 상태, 경계 장부, 질량/에너지 잔차

관측 압력·DPT·온도는 비교 열로 넣고, 모델 경계를 결정하는 유량·밸브 상태와
혼동하지 않는다. 압력 센서가 게이지압이면 먼저 절대압으로 바꾼 뒤 입력한다.
