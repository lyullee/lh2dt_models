# 비공개 설비 입력 스키마

실제 자산 값은 패키지에 포함하지 않고 기관 내부 파일로 보관한다. 아래 구조는
TK-1101/TK-1102와 같은 저장탱크를 동일 물리모델 클래스의 별도 인스턴스로
연결하기 위한 최소 계약이다.

```json
{
  "schema_version": "0.2",
  "privacy": "private",
  "parameter_policy": {"plant_data_optimization": false},
  "assets": [
    {
      "asset_id": "SITE_TANK_A",
      "component_model": "layered_tank",
      "model_parameters": {
        "volume_m3": 0.0,
        "connected_vapor_volume_m3": 0.0
      },
      "parameter_evidence": {
        "volume_m3": {
          "value": 0.0,
          "unit": "m3",
          "source": "approved GA drawing",
          "uncertainty": 0.0,
          "applies_to": "SITE_TANK_A",
          "valid_range": [0.0, 100.0]
        }
      }
    }
  ]
}
```

필수 관리 항목은 다음과 같다.

- 형상: 내경, 직관부 길이, 경판 깊이, 총 체적
- 열경계: 벽체 열용량, 외기 UA, 액체·기상 접촉부 UA, 진공·MLI·지지대 경로
- 연결부: 배관·노즐 데드볼륨, 연결부 벽체 열용량, 밸브·벤트 경계
- 초기조건: 절대압, 액체 체적분율 또는 DPT 액위 환산, 상·하부 벽체 온도
- 계측: 태그, 단위, 절대/게이지 기준, HART PV/SV/TV/QV 역할, 품질 플래그
- 출처: 문서/화면/제조사 자료의 식별자, 적용 자산, 불확도, 적용 범위

`parameter_evidence` 값과 `model_parameters` 값이 다르면 감사가 실패한다. 빈
값을 운영 시계열 평균으로 자동 채우지 않으며, 누락 파라미터는 모델 생성 전
확인 대상으로 남긴다.
